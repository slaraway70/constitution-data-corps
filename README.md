### VISUAL IMPERATIVE — DASHBOARD PRINCIPLES
This dashboard was built using principles from **Lindy Ryan, Rutgers University MBS — Data Visualization (The Visual Imperative: Creating a visual culture of data discovery)** — Professor Ryan was my professor for my master's program.

**Principles Applied:**
1. **Story First, Then Data:** Narrative arc — From Blockage → Documentation → Recruitment → Data Corps
2. **Visual Culture of Discovery:** Interactive filters by Type, Politician, Platform — user discovers pattern, not told pattern
3. **Clarity Over Decoration:** Clean grid, Lincoln colors, ample whitespace, labeled axes, monospace data
4. **Multiple Perspectives:** Timeline + Stacked Bar + Donut + Heatmap + Keyword Frequency = same truth, different lenses

**Dashboard Features:**
- 📈 Timeline: Escalation from 2024 to July 2026 spike
- 📊 Stacked Bar: Event type by politician cluster (Nancy Mace = 6, Meta/System = 6)
- 🍩 Donut: Platform distribution (Facebook 12, Instagram 3, LinkedIn 1)
- 🗓️ Heatmap: July 2026 intensity calendar
- 🔤 Keyword Frequency: Facebook, Blocked, Mace, @mentions, censorship, rate limit
